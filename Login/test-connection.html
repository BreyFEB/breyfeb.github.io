🔧 Diagnóstico de Conexión Strapi

Este archivo te ayudará a diagnosticar problemas con el servidor Strapi.

📋 Instrucciones para configurar Strapi

1. Instalar y ejecutar Strapi

# Si no tienes Strapi instalado: npx create-strapi-app@latest my-project --quickstart # Si ya lo tienes instalado: cd tu-proyecto-strapi npm run develop

2. Verificar que Strapi esté corriendo

  • Strapi debería estar ejecutándose en http://localhost:1337
  • Deberías poder acceder al panel de administración en http://localhost:1337/admin

3. Configurar permisos

  • Ve a Settings → Users & Permissions → Roles
  • En Public: Habilita auth/local/register y auth/local
  • En Authenticated: Habilita los permisos necesarios

4. Solucionar problemas de CORS

// En config/middlewares.js module.exports = [ // ... { name: 'strapi::cors', config: { enabled: true, headers: '*', origin: ['http://localhost:3000', 'http://127.0.0.1:3000', 'file://'] } }, // ... ];
